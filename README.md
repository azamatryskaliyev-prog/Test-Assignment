# Data Analyst — Test Assignment

## Описание проекта

В данном репозитории представлены выполненные тестовые задания по анализу данных с использованием Python и Microsoft Excel.

## 1. Тестовое задание Python

Файл: `Тестовое_задание_Python_анализ(1).ipynb`

Решение аналитического тестового задания в среде Jupyter Notebook.

Основные направления работы:
- Загрузка и изучение данных.
- Анализ информации.
- Выполнение расчётов с использованием Python.
- Представление результатов в Jupyter Notebook.

## 2. Тестовое задание Excel — Novartis

Файл: `Novartis_Pharma_Services_AG_ответы(1).xlsx`

Excel-файл с выполненными заданиями и ответами на вопросы тестирования.

## Используемые инструменты

- Python
- Jupyter Notebook
- Microsoft Excel

## Цель проекта

Демонстрация практических навыков анализа данных, выполнения аналитических заданий и представления результатов.
